# Android agent skills setup

This branch adds project-level rules and reusable Android skills only. It does not change application source, Firebase, signing, or release configuration.

Recommended upstream sources:
- Kotlin agent skills: https://github.com/Kotlin/kotlin-agent-skills
- Android agent skills collection: https://github.com/piyushverma0/android-agent-skills
- General discovery: https://skills.sh/

Review each repository's license, current maintenance, dependencies, and scope before installation. Skill installation depends on the coding environment; this branch does not install skills globally into ChatGPT or other devices.
